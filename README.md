# Tundra World

Tundra World replaces the overworld with an all-frozen landscape of glaciers, ice spikes, snowfields, and frozen seas. It is built on Isekai API.

## Requirements

- Minecraft 1.21.1 with NeoForge.
- Isekai API 2.0.0 or newer, below 3.0.0, as required by the loader metadata.

Create a new world after installing the JARs. Tundra World replaces overworld terrain generation and cannot be combined with another mod that also replaces the overworld generator.
